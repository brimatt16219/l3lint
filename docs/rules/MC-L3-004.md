# MC-L3-004: Quantity missing or not above 0

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L3 |
| Brand | mastercard |
| Impact | blocksLevel3 |
| Effective | always |
| Pack | l3lint.rules.mastercard 1.0.0 |

## Requirement

Each line needs a quantity above 0 for Data Rate III.

## Why

Mastercard Level 3 line items need a quantity.

## Check

`required /lineItems/*/quantity (allowZero: false; positiveOnly: true; report: each)`

## Applies to

- card products: corporate, purchasing
- skipped when the MCC is on: mastercardLevel2ExcludedMcc, mastercardLevel3ExcludedMcc
- skipped when /card/productCode in MBS, MEF

## Message

`Line {index} quantity is {actual}; it must be above 0.`

## Fix

Send the quantity.

## Sources

- <https://inte2.epicor.com/en/products/digital-commerce/payments/ptw-credit-card-processing/understanding-levels-2-and-3/>
