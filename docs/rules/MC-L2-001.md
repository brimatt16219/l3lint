# MC-L2-001: Tax outside 0.1% to 30% of the amount

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L2 |
| Brand | mastercard |
| Impact | blocksLevel2 |
| Effective | always |
| Pack | l3lint.rules.mastercard 1.0.0 |

## Requirement

Mastercard Level 2 needs tax between 0.1% and 30% of the amount, unless the MCC is exempt or the sale is marked exempt.

## Why

Tax outside the range is treated as not real, so the transaction loses Data Rate II.

## Check

`ratio /tax/amount, /amount (min: 0.001; max: 0.30)`

## Applies to

- card products: business, corporate, purchasing
- skipped when the MCC is on: mastercardLevel2ExcludedMcc, mastercardTaxExemptMcc
- skipped when /tax/indicator equals exempt

## Message

`Tax is {ratio} of the amount; Mastercard Level 2 needs {min} to {max}.`

## Fix

Correct the tax amount or mark the sale exempt.

## Sources

- <https://developer.paypal.com/braintree/docs/reference/general/level-2-and-3-processing/required-fields/dotnet/>
- <https://docs.stripe.com/payments/payment-line-items>
