# AMEX-FMT-001: Advice text over 4 lines or 40 characters a line

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L3 |
| Brand | amex |
| Impact | truncation |
| Effective | always |
| Pack | l3lint.rules.amex 1.0.0 |

## Requirement

Amex transaction advice text holds at most 4 lines of 40 characters each.

## Why

Text beyond the format is cut off when the processor builds the Amex record.

## Check

`custom (check: AdviceText)`

## Applies to

- runs at error under profiles jpmorgan, amex-advice-text or with --strict-profiles, otherwise as a warning

## Message

`Advice text has {count} lines; Amex accepts at most {max}.`

## Fix

Condense the text.

## Sources

- <https://developer.payments.jpmorgan.com/docs/commerce/online-payments/capabilities/online-payments/payment-methods/cards/commercialcards>
