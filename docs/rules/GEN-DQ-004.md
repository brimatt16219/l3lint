# GEN-DQ-004: Filler customer code or PO

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | inferred |
| Level | L2 |
| Brand | all brands |
| Impact | riskVisaValidation |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

The customer code and purchase order number should be the buyer's real reference.

## Why

Values such as 123456 are typed to get past a required field and do not help the buyer reconcile.

## Check

`custom (check: FillerReference)`

## Message

`"{actual}" at {field} looks like filler, not the buyer's reference.`

## Fix

Ask the buyer for their real reference.

## Sources

- <https://blog.payroc.com/what-you-need-to-know-about-visas-new-cedp-program>
