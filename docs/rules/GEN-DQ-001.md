# GEN-DQ-001: Placeholder description

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | inferred |
| Level | L3 |
| Brand | all brands |
| Impact | riskVisaValidation |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

Each line description should name the real product or service.

## Why

Visa rejects generic descriptions such as "Item" or "N/A"; other brands pass them through to the buyer's statement unchanged.

## Check

`custom (check: PlaceholderDescription)`

## Message

`Line {index} description "{actual}" is a placeholder, not an item name.`

## Fix

Use the real product or service name.

## Sources

- <https://www.versapay.com/cedp>
- <https://merchantcostconsulting.com/lower-credit-card-processing-fees/how-to-qualify-cedp-rates/>
- <https://finix.com/resources/blogs/visa-level-2-3-programs-changing-cedp>
