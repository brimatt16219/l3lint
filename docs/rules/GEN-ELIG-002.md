# GEN-ELIG-002: Card product unknown

| Property | Value |
| --- | --- |
| Severity | information |
| Confidence | policy |
| Level | general |
| Brand | all brands |
| Impact | hygiene |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

Send the card product so eligibility checks can run.

## Why

Without the card product l3lint cannot tell whether an enhanced-data rate is possible.

## Check

`required /card/product (allowZero: false; positiveOnly: false; report: each)`

## Message

`The card product is unknown, so eligibility checks cannot run.`

## Fix

Pass card.product to enable eligibility checks.

## Sources

- <https://docs.stripe.com/payments/payment-line-items>
