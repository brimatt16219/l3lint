# VISA-ELIG-002: MCC excluded from Product 3

| Property | Value |
| --- | --- |
| Severity | information |
| Confidence | processor-doc |
| Level | general |
| Brand | visa |
| Impact | noBenefit |
| Effective | from 2025-10-17 |
| Pack | l3lint.rules.visa 1.0.0 |

## Requirement

Visa excludes some MCCs (travel, lodging, restaurants and others) from Product 3.

## Why

At these MCCs enhanced data earns no Product 3 rate, so data errors there do not cost a downgrade.

## Check

`inList /merchant/mcc (list: visaProduct3ExcludedMcc; mode: deny; caseInsensitive: false; allowMissing: true)`

## Message

`MCC {actual} is excluded from Visa Product 3, so no enhanced-data rate is available.`

## Fix

None; no Product 3 rate.

## Sources

- <https://docs.stripe.com/payments/payment-line-items>
