# VISA-L3-015: Commodity code over 12 characters or not alphanumeric

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L3 |
| Brand | visa |
| Impact | blocksLevel3 |
| Effective | always |
| Pack | l3lint.rules.visa 1.0.0 |

## Requirement

The commodity code must be up to 12 letters or digits with no spaces.

## Why

Gateways reject or strip codes with spaces or punctuation.

## Check

`pattern /lineItems/*/commodityCode (regex: ^[A-Za-z0-9]{1,12}$)`

## Message

`Line {index} commodity code "{actual}" must be up to 12 letters or digits with no spaces.`

## Fix

Send the bare code, for example 42132203.

## Sources

- <https://docs.stripe.com/payments/payment-line-items>

## Replaces at the same path

GEN-FMT-006
