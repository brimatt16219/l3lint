# GEN-DQ-006: Generic or malformed commodity code

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | inferred |
| Level | L3 |
| Brand | all brands |
| Impact | riskVisaValidation |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

Commodity codes should be specific 8-digit UNSPSC codes.

## Why

Segment-level or zero codes say nothing about the item, and Visa's review treats them as filler.

## Check

`custom (check: CommodityCodeShape)`

## Message

`Line {index} commodity code {actual} looks generic or malformed: {detail}.`

## Fix

Use the most specific 8-digit UNSPSC code.

## Sources

- <https://blog.payroc.com/what-you-need-to-know-about-visas-new-cedp-program>
- <https://docs.stripe.com/payments/payment-line-items>

## Notes

The check is structural only; l3lint does not ship the UNSPSC code list.
