# MC-L3-005: Unit of measure not on the Mastercard list

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L3 |
| Brand | mastercard |
| Impact | blocksLevel3 |
| Effective | from 2025-10-01 |
| Pack | l3lint.rules.mastercard 1.0.0 |

## Requirement

Since October 2025, Mastercard accepts only the codes on its unit-of-measure list.

## Why

Units outside the fixed list fail Data Rate III.

## Check

`inList /lineItems/*/unitOfMeasure (list: mastercardUom; mode: allow; caseInsensitive: false; allowMissing: false)`

## Applies to

- card products: corporate, purchasing
- skipped when the MCC is on: mastercardLevel2ExcludedMcc, mastercardLevel3ExcludedMcc
- skipped when /card/productCode in MBS, MEF

## Message

`Line {index} unit of measure {actual} is not on the Mastercard list.`

## Fix

Map to a listed code such as EAC or PCE.

## Sources

- <https://developer.payments.jpmorgan.com/docs/commerce/online-payments/capabilities/online-payments/payment-methods/cards/commercialcards>
- <https://www.weaudit.com/level-3-credit-card-processing/>
- <https://navan.com/resources/glossary/level-3-data>

## Replaces at the same path

GEN-FMT-006
