# AMEX-L2-002: PO number over 22 characters

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | processor-doc |
| Level | L2 |
| Brand | amex |
| Impact | truncation |
| Effective | always |
| Pack | l3lint.rules.amex 1.0.0 |

## Requirement

The Amex purchase order number holds at most 22 characters.

## Why

Longer PO numbers are truncated in the Amex record.

## Check

`maxLength /order/purchaseOrderNumber (/order/purchaseOrderNumber: 22)`

## Message

`The PO number is {length} characters; Amex keeps {max}.`

## Fix

Shorten it.

## Sources

- <https://developer.mastercard.com/mastercard-gateway/documentation/gateway-features/trans-enrich-data/order-and-line-item-data/level-2-and-3/level2-3-data-for-amex-acq/>

## Replaces at the same path

GEN-FMT-006
