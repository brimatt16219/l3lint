# GEN-FMT-001: Payload does not match the canonical schema

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | policy |
| Level | general |
| Brand | all brands |
| Impact | hygiene |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

The payload must match the canonical JSON Schema (schema v1).

## Why

A field with the wrong type or name cannot be checked, so every rule that needs it is skipped.

## Check

`custom (check: Schema)`

## Message

`{detail}`

## Fix

Correct the field named in the path.

## Sources

- <https://json-schema.org/draft/2020-12/json-schema-core>
