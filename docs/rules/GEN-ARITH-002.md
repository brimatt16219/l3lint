# GEN-ARITH-002: Transaction amount does not match the line totals and summary amounts

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L3 |
| Brand | all brands |
| Impact | blocksLevel3 |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

The amount must equal the sum of line totals (less included line tax) + tax + freight + duty + shipping tax - header discount, within the total tolerance.

## Why

A total that does not reconcile is one of the patterns Visa's validation rejects.

## Check

`custom (check: TransactionTotal)`

## Message

`The amount is {reported}; lines and summary amounts add up to {expected} (difference {difference}).`

## Fix

Recompute the amount, or fix the line or summary values.

## Sources

- <https://developer.paypal.com/braintree/docs/reference/general/level-2-and-3-processing/required-fields/dotnet/>
- <https://developer.payments.jpmorgan.com/docs/commerce/online-payments/capabilities/online-payments/payment-methods/cards/commercialcards>
- <https://curbstone.com/new-data-requirements-cedp/>
