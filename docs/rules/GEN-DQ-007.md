# GEN-DQ-007: Same description or product code across most of a batch

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | inferred |
| Level | L3 |
| Brand | all brands |
| Impact | riskVisaValidation |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

Across a batch, line data should vary as real invoices do.

## Why

One value on most transactions in a run shows line data copied from a template, which CEDP flags.

## Check

`custom (check: StaticBatchData)`

## Message

`"{actual}" appears at {field} on {count} of {transactions} transactions ({share}).`

## Fix

Pull line data from the invoice, not a template.

## Sources

- <https://blog.payroc.com/what-you-need-to-know-about-visas-new-cedp-program>
- <https://curbstone.com/new-data-requirements-cedp/>

## Notes

Thresholds (at least 20 transactions, 80% share) are inferred and configurable under rules.batch.
