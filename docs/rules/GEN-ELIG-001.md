# GEN-ELIG-001: Consumer card

| Property | Value |
| --- | --- |
| Severity | information |
| Confidence | processor-doc |
| Level | general |
| Brand | all brands |
| Impact | noBenefit |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

Enhanced data earns a rate only on commercial cards.

## Why

Brands pay enhanced-data rates for business, corporate, purchasing and fleet cards, never for consumer cards.

## Check

`inList /card/product (values: consumer; mode: deny; caseInsensitive: false; allowMissing: true)`

## Message

`This is a consumer card, so no enhanced-data rate is available.`

## Fix

None; enhanced data earns no rate on consumer cards.

## Sources

- <https://docs.stripe.com/payments/payment-line-items>

## Replaces at the same path

VISA-ELIG-001
