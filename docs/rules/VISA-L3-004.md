# VISA-L3-004: Commodity code is required for Product 3

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L3 |
| Brand | visa |
| Impact | blocksLevel3 |
| Effective | from 2025-10-17 |
| Pack | l3lint.rules.visa 1.0.0 |

## Requirement

Each line needs a commodity code, usually an 8-digit UNSPSC code, for Product 3.

## Why

The commodity code is one of the 12 Product 3 fields; it classifies what was bought.

## Check

`required /lineItems/*/commodityCode (allowZero: false; positiveOnly: false; report: each)`

## Applies to

- card products: business, corporate, purchasing, fleet
- skipped when the MCC is on: visaProduct3ExcludedMcc
- skipped when /card/isFederalGovernment equals true and /merchant/mcc inList visaFederalExcludedMcc

## Message

`Line {index} has no commodity code; Visa needs one on every line for Product 3.`

## Fix

Add the most specific 8-digit UNSPSC code for this item.

## Sources

- <https://blog.payroc.com/what-you-need-to-know-about-visas-new-cedp-program>
