# VISA-L3-010: Line-item detail indicator missing

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | processor-doc |
| Level | L3 |
| Brand | visa |
| Impact | blocksLevel3 |
| Effective | from 2025-10-17 |
| Pack | l3lint.rules.visa 1.0.0 |

## Requirement

Product 3 line items carry a line-item detail indicator, often set by the processor.

## Why

The detail indicator marks the record as line-item detail; many processors fill it, so this is a warning.

## Check

`required /lineItems/*/detailIndicator (allowZero: false; positiveOnly: false; report: once)`

## Applies to

- card products: business, corporate, purchasing, fleet
- skipped when the MCC is on: visaProduct3ExcludedMcc
- skipped when /card/isFederalGovernment equals true and /merchant/mcc inList visaFederalExcludedMcc

## Message

`{count} line(s) have no line-item detail indicator, starting with line {index}.`

## Fix

Confirm your processor sets it.

## Sources

- <https://blog.payroc.com/what-you-need-to-know-about-visas-new-cedp-program>
- <https://community.developer.cybersource.com/t5/Integration-and-Testing/Submitting-Level-2-Data/m-p/60293>

## Notes

Checked for presence only; no public list of valid values was found (ADR-0015). Reported once per transaction (ADR-0039).
