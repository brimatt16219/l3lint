# GEN-FMT-004: Descriptive text has unsupported characters

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | processor-doc |
| Level | general |
| Brand | all brands |
| Impact | truncation |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

Descriptions and advice text should use only letters, digits, space, apostrophe, period and hyphen.

## Why

Some brands print other characters as spaces, which garbles the line on the buyer's statement.

## Check

`pattern /lineItems/*/description, /amex/adviceText/* (regex: ^[A-Za-z0-9 '.-]*$)`

## Message

`Text at {field} has characters some brands print as spaces: {actual}`

## Fix

Replace them; some brands print them as spaces.

## Sources

- <https://developer.paypal.com/braintree/docs/reference/general/level-2-and-3-processing/required-fields/dotnet/>
