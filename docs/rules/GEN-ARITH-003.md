# GEN-ARITH-003: Header tax differs from the sum of line taxes

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | processor-doc |
| Level | L3 |
| Brand | all brands |
| Impact | riskVisaValidation |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

When any line carries tax, the header tax must equal the sum of line taxes within the total tolerance.

## Why

Inconsistent tax suggests one of the two was not computed from the invoice.

## Check

`custom (check: TaxConsistency)`

## Message

`Header tax is {reported}, but the line taxes add up to {expected}.`

## Fix

Make header tax the sum of line taxes.

## Sources

- <https://developer.paypal.com/braintree/docs/reference/general/level-2-and-3-processing/required-fields/dotnet/>
- <https://curbstone.com/new-data-requirements-cedp/>
