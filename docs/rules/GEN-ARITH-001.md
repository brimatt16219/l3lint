# GEN-ARITH-001: Line total does not match quantity times unit cost less discount

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L3 |
| Brand | all brands |
| Impact | blocksLevel3 |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

Each line total must equal round(quantity x unit cost) - line discount (+ line tax when the total includes tax), within the line tolerance.

## Why

Visa's quality review and several gateways reject line items whose math does not reconcile.

## Check

`custom (check: LineTotal)`

## Message

`Line {index} total is {reported}; quantity, unit cost and discount give {expected} (difference {difference}).`

## Fix

Recompute the line total.

## Sources

- <https://inte2.epicor.com/en/products/digital-commerce/payments/ptw-credit-card-processing/understanding-levels-2-and-3/>
- <https://curbstone.com/new-data-requirements-cedp/>
- <https://docs.stripe.com/payments/payment-line-items>

## Notes

Derived totals (for example Stripe, which sends no line total) are skipped instead of trivially passing.
