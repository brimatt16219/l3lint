# VISA-L2-002: Tax indicator missing

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L2 |
| Brand | visa |
| Impact | blocksLevel2 |
| Effective | until 2026-04-17 (last day the rule applies) |
| Pack | l3lint.rules.visa 1.0.0 |

## Requirement

Until the Level 2 sunset, Visa Level 2 needed the tax indicator.

## Why

The indicator tells the network whether a zero tax means exempt or missing.

## Check

`required /tax/indicator (allowZero: false; positiveOnly: false; report: each)`

## Applies to

- card products: business, corporate, purchasing, fleet

## Message

`The tax indicator is missing.`

## Fix

Send `taxable` or `exempt`.

## Sources

- <https://blog.payroc.com/what-you-need-to-know-about-visas-new-cedp-program>
- <https://developer.payments.jpmorgan.com/docs/commerce/online-payments/capabilities/online-payments/payment-methods/cards/commercialcards>
