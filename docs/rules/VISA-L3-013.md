# VISA-L3-013: Freight without shipping postal codes or country

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | processor-doc |
| Level | L3 |
| Brand | visa |
| Impact | blocksLevel3 |
| Effective | from 2025-10-17 |
| Pack | l3lint.rules.visa 1.0.0 |

## Requirement

When freight is above 0, send the ship-from and ship-to postal codes and the destination country.

## Why

Shipping data is conditional for Product 3 and expected whenever goods ship.

## Check

`required /shipping/fromPostalCode, /shipping/toPostalCode, /shipping/toCountry (allowZero: false; positiveOnly: false; report: each)`

## Applies to

- card products: business, corporate, purchasing, fleet
- skipped when the MCC is on: visaProduct3ExcludedMcc
- only when /amounts/freight greaterThan 0

## Message

`Freight is charged but {field} is missing.`

## Fix

Send the shipping postal codes and country.

## Sources

- <https://blog.payroc.com/what-you-need-to-know-about-visas-new-cedp-program>
