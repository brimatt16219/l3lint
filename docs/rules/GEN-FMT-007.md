# GEN-FMT-007: Line sequence numbers missing, duplicated or not contiguous

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L3 |
| Brand | all brands |
| Impact | blocksLevel3 |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

Lines must be numbered 1, 2, 3 in order, with no gaps or repeats.

## Why

Processors use the sequence number to keep line items in order; a gap or repeat can drop or reorder lines.

## Check

`custom (check: Sequence)`

## Message

`Line {index} has sequence {actual}; it should be {expected}.`

## Fix

Number lines 1, 2, 3 in order.

## Sources

- <https://community.developer.cybersource.com/t5/Integration-and-Testing/Submitting-Level-2-Data/m-p/60293>
