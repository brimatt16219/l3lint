# MC-L3-008: Line tax indicator, discount indicator or tax type missing

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | processor-doc |
| Level | L3 |
| Brand | mastercard |
| Impact | blocksLevel3 |
| Effective | always |
| Pack | l3lint.rules.mastercard 1.0.0 |

## Requirement

One large processor requires a line tax indicator, a discount indicator when a line has a discount, and a tax type code when a line has tax.

## Why

Required by J.P. Morgan for Mastercard Level 3; a warning elsewhere.

## Check

`custom (check: MastercardLineIndicators)`

## Applies to

- card products: corporate, purchasing
- skipped when the MCC is on: mastercardLevel2ExcludedMcc, mastercardLevel3ExcludedMcc
- skipped when /card/productCode in MBS, MEF
- runs at warning under profiles jpmorgan or with --strict-profiles, otherwise as a warning

## Message

`Line {index} is missing {field}.`

## Fix

Send the indicators.

## Sources

- <https://developer.payments.jpmorgan.com/docs/commerce/online-payments/capabilities/online-payments/payment-methods/cards/commercialcards>
