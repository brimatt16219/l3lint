# GEN-FMT-003: Amount not positive, or more decimals than the currency allows

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | policy |
| Level | general |
| Brand | all brands |
| Impact | hygiene |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

The amount must be above 0, and no amount may have more decimals than the currency exponent. Unit cost is exempt.

## Why

Gateways reject or round amounts with extra decimals, which breaks line-item arithmetic.

## Check

`custom (check: AmountPrecision)`

## Message

`{field} is {actual}, which has more decimals than {currency} allows.`

## Fix

Round to the currency exponent before sending.

## Sources

- <https://www.iso.org/iso-4217-currency-codes.html>
- <https://developer.paypal.com/braintree/docs/reference/general/level-2-and-3-processing/required-fields/dotnet/>
