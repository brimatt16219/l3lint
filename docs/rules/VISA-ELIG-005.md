# VISA-ELIG-005: Card not present without a billing postal code

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | processor-doc |
| Level | L2 |
| Brand | visa |
| Impact | blocksLevel3 |
| Effective | always |
| Pack | l3lint.rules.visa 1.0.0 |

## Requirement

Card-not-present sales should carry the billing postal code for address verification.

## Why

Address verification data is expected for the lower commercial rates on card-not-present sales.

## Check

`required /billing/postalCode (allowZero: false; positiveOnly: false; report: each)`

## Applies to

- only when /channel equals cardNotPresent

## Message

`The sale is card not present but has no billing postal code.`

## Fix

Send the billing postal code for address verification.

## Sources

- <https://docs.adyen.com/payment-methods/cards/enhanced-scheme-data>
