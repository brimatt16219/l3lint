# MC-L3-006: Unit price or extended amount missing

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L3 |
| Brand | mastercard |
| Impact | blocksLevel3 |
| Effective | always |
| Pack | l3lint.rules.mastercard 1.0.0 |

## Requirement

Each line needs its unit price and extended amount for Data Rate III.

## Why

Mastercard Level 3 line items need both amounts.

## Check

`required /lineItems/*/unitCost, /lineItems/*/total (allowZero: true; positiveOnly: false; report: each)`

## Applies to

- card products: corporate, purchasing
- skipped when the MCC is on: mastercardLevel2ExcludedMcc, mastercardLevel3ExcludedMcc
- skipped when /card/productCode in MBS, MEF

## Message

`Line {index} is missing {field}.`

## Fix

Send both.

## Sources

- <https://inte2.epicor.com/en/products/digital-commerce/payments/ptw-credit-card-processing/understanding-levels-2-and-3/>
