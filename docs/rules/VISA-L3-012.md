# VISA-L3-012: Tax must be positive or explicitly exempt

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L3 |
| Brand | visa |
| Impact | riskVisaValidation |
| Effective | from 2025-10-17 |
| Pack | l3lint.rules.visa 1.0.0 |

## Requirement

Under CEDP, tax must be above 0, or the sale must be flagged exempt with tax.indicator.

## Why

A bare zero tax is not accepted as a tax-exempt sale; exemption must be flagged explicitly.

## Check

`custom (check: ExplicitTax)`

## Applies to

- card products: business, corporate, purchasing, fleet
- skipped when the MCC is on: visaProduct3ExcludedMcc
- skipped when /card/isFederalGovernment equals true and /merchant/mcc inList visaFederalExcludedMcc

## Message

`Tax is {actual} and the sale is not marked exempt.`

## Fix

Send the tax amount, or set tax.indicator to exempt.

## Sources

- <https://www.versapay.com/cedp>
- <https://www.forbes.com/councils/forbesbusinesscouncil/2025/06/27/what-merchants-should-know-about-visas-commercial-enhanced-data-program/>
