# VISA-L2-003: Purchasing card at a fuel MCC without a customer code

| Property | Value |
| --- | --- |
| Severity | error |
| Confidence | processor-doc |
| Level | L2 |
| Brand | visa |
| Impact | blocksLevel2 |
| Effective | until 2026-04-17 (last day the rule applies) |
| Pack | l3lint.rules.visa 1.0.0 |

## Requirement

Until the Level 2 sunset, purchasing cards at fuel MCCs needed a customer code instead of the tax range.

## Why

At fuel MCCs the customer code replaced the tax check for Level 2.

## Check

`required /customer/reference (allowZero: false; positiveOnly: false; report: each)`

## Applies to

- card products: purchasing
- only when the MCC is on: visaFuelMcc

## Message

`A purchasing card at a fuel MCC needs a customer code.`

## Fix

Send the customer code.

## Sources

- <https://blog.payroc.com/what-you-need-to-know-about-visas-new-cedp-program>
- <https://developer.paypal.com/braintree/docs/reference/general/level-2-and-3-processing/required-fields/dotnet/>
