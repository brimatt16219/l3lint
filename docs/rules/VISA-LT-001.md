# VISA-LT-001: Large Ticket rates may be cheaper

| Property | Value |
| --- | --- |
| Severity | information |
| Confidence | processor-doc |
| Level | general |
| Brand | visa |
| Impact | noBenefit |
| Effective | always |
| Pack | l3lint.rules.visa 1.0.0 |

## Requirement

At high amounts on corporate and purchasing cards, Large Ticket interchange may cost less than Product 3.

## Why

Large Ticket rates use the same CEDP flag; the break-even amount moves with each rate schedule, so it is computed from the user's rate table.

## Check

`custom (check: LargeTicket)`

## Message

`The amount {actual} is above the Large Ticket break-even of {expected} in rate table {detail}.`

## Fix

Ask your processor about Large Ticket.

## Sources

- <https://paypal.com/us/brc/article/visas-commercial-enhanced-data-program>
- <https://blog.payroc.com/what-you-need-to-know-about-visas-new-cedp-program>

## Notes

Runs only when --rates supplies Visa largeTicket and product3 categories for the card product (ADR-0018). One source estimated the break-even near 7,756 USD; the rule never hard-codes it.
