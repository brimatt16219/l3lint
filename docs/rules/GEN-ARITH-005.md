# GEN-ARITH-005: Discount counted twice

| Property | Value |
| --- | --- |
| Severity | warning |
| Confidence | processor-doc |
| Level | L3 |
| Brand | all brands |
| Impact | riskVisaValidation |
| Effective | always |
| Pack | l3lint.rules.general 1.0.0 |

## Requirement

A discount belongs at the header or on the lines, not both.

## Why

When the header discount equals the sum of line discounts, the same discount is likely subtracted twice.

## Check

`custom (check: DoubleDiscount)`

## Message

`The header discount {reported} equals the sum of line discounts, so it is likely counted twice.`

## Fix

Send the discount at one level only.

## Sources

- <https://curbstone.com/new-data-requirements-cedp/>
- <https://inte2.epicor.com/en/products/digital-commerce/payments/ptw-credit-card-processing/understanding-levels-2-and-3/>
