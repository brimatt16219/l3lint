# L3Lint.Reporting

The l3lint output writers: text, JSON (the results schema), SARIF 2.1.0 for GitHub code scanning, JUnit XML for CI dashboards and Markdown for job summaries. It also renders rule reference pages.

```text
dotnet add package L3Lint.Reporting
```

`L3Lint.Hosting` already includes this package.

Documentation: https://brimatt16219.github.io/l3lint/articles/output-formats.html
